\# AI Prompt Cheatsheet



1\. Explain this GitHub issue in simple terms.



2\. Help me understand the repository structure related to this issue.



3\. Help me reproduce this bug without fixing it.



4\. What are the likely root causes of this error?



5\. Which files are likely responsible for this issue?



6\. Review my proposed solution against the issue requirements.



7\. Identify edge cases I should test.



8\. Suggest tests for my implementation.



9\. Review my PR description for clarity and completeness.



10\. Explain this reviewer feedback and what changes are required.



11\. Check whether my change is limited to the issue scope.



12\. Review my code for unnecessary changes before I submit the PR.
